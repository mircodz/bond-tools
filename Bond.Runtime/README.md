# BondTools.Runtime

Serialization for C# generated by `bond generate csharp --serialization`, compatible with Bond's Compact Binary (v1) protocol. Generated code writes and reads fields directly: no reflection and no runtime code generation, so it works with trimming and NativeAOT. It writes the bytes upstream Bond writes, and reads any payload, valid or not, as upstream Bond reads it.

```csharp
byte[] bytes = order.Serialize();          // also Serialize(IBufferWriter<byte>) and Serialize(Stream)
Order copy = Order.Deserialize(bytes);     // also ReadOnlySequence<byte> and Stream
```

## Generic structs

A generic struct takes a codec for each type parameter:

```csharp
var codec = BondCodec.Struct<Order>();
byte[] bytes = page.Serialize(codec);
Page<Order> copy = Page<Order>.Deserialize(bytes, codec);
```

`BondCodec` has a codec for every Bond type, such as `BondCodec.WString` and `BondCodec.Vector(BondCodec.Int32)`.

## `bonded<T>`

A `bonded<T>` field reads as a `BondedPayload<T>`: the struct's bytes, deserialized by `Deserialize()` and written back unchanged, including fields `T` does not know. Values such as `new Bond.Bonded<T>(value)` are written as upstream Bond writes them.

## Custom type mappings

Values of custom-mapped types are converted by the `BondTypeAliasConverter` class in their struct's namespace, as with upstream Bond: `Convert(value, default(BondType))` before writing and `Convert(value, default(MappedType))` after reading.

## Performance

Mean time per call on an Intel i7-12700KF with .NET 10; upstream is Bond.Runtime.CSharp 13.0.2 with Bond.IO.Unsafe buffers.

| Write | bond-tools | upstream | Δ |
|---|--:|--:|--:|
| Order with nested structs, strings and maps | 297 ns | 586 ns | -49% |
| 100 small structs | 1.40 µs | 1.95 µs | -28% |
| 100 `int32` | 99 ns | 228 ns | -56% |
| 1,000 `double` | 1.05 µs | 1.69 µs | -38% |
| `map<string, string>`, 100 entries | 1.47 µs | 2.99 µs | -51% |
| `map<int32, double>`, 100 entries | 203 ns | 1.11 µs | -82% |
| 4 KB order using most Bond types | 4.10 µs | 6.80 µs | -40% |

| Read | bond-tools | upstream | Δ |
|---|--:|--:|--:|
| Order with nested structs, strings and maps | 617 ns | 792 ns | -22% |
| 100 small structs | 2.26 µs | 3.34 µs | -32% |
| 100 `int32` | 182 ns | 344 ns | -47% |
| 1,000 `double` | 1.44 µs | 3.23 µs | -55% |
| `map<string, string>`, 100 entries | 2.79 µs | 3.91 µs | -29% |
| `map<int32, double>`, 100 entries | 513 ns | 1.74 µs | -70% |
| 4 KB order using most Bond types | 7.52 µs | 11.4 µs | -34% |

`dotnet run -c Release --project benchmarks` runs them. [benchmarks/RESULTS.md](../benchmarks/RESULTS.md) has the full results, also for an Apple M4 Pro.
